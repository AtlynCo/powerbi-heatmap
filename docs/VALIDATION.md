Recorded September 9, 2026 on Windows with Node 24.17.0, npm 11.13.0, PowerShell 7, TypeScript 5.9.3, Power BI visuals tools 7.2.1, SDK package 5.11.1 / host API 5.11.0, and Playwright Chromium. This is local engineering evidence, **not Microsoft certification, native Power BI proof, or publication approval**.

## What was exercised

Numerical coverage includes host order/identities, canonical multi-measure matrix ordinals and subtotal offsets, sparse/blank/invalid/highlight states, caps and traversal limits, raw ratios, additive consent, independent row/column/global domains, signed/diverging scales, zero and extreme-number denominators, overflow-resistant shares, supplied denominators on partial data, missing-state preservation during blocked calculations, and black/white text contrast across palettes.

The Chromium harness instantiates the packaged plugin through a deliberately mocked Power BI host. It checks row/column/cell identity calls, Ctrl multiselection, clear, incoming selection/highlights including zero, native-tooltip/context-menu API calls, literal user text, dynamic cell formats, keyboard focus/sticky geometry, resize, query replacement while fetching, partial-fetch rejection, maximum label sizes at 240 x 160, high contrast/RTL, exact bundled legal text, and no observed page requests during the representative render/interactions. A 20,000-cell package render completed and retained exactly 20,000 cells. This is a boundedness check, not a general performance SLA.

Real Chromium screenshots were captured at **120 x 80, 240 x 160, 720 x 480, and 1440 x 900** using synthetic host fixtures. Empty, invalid, and partial data were also exercised. Screenshots depict the packaged renderer in a browser harness; they are **not Power BI Desktop/Service screenshots or AppSource submission evidence**.

## Build and dependency safeguards

The scaffold came from official `pbiviz new`. Packaging remains the official SDK path. `--all-locales` avoids the confirmed formattingutils 7 locale-pruning loader ESM failure without editing dependencies. The Windows wrapper generated file-only, untrusted certificates in isolated ignored tool-home storage; named certificate/private/password files were removed after successful and failed builds. No certificate-store/trust changes or background services were needed. Linux/macOS wrapper and CI execution are not claimed as locally verified.

Dependencies are pinned in the lockfile. Full-tree advisories initially involved build-server `qs` and `sockjs`'s `uuid`; scoped overrides use `qs` 6.16.0 and `uuid` 11.1.1. The existing SockJS code uses `require('uuid').v4`, which the override retains. These are development dependencies, not runtime licensing/network services. Audit results are time-sensitive and must be rerun for later candidates.
